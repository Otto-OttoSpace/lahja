لهجة · Otto

Every string, every language.

Lahja catches the user-facing strings your code (and your AI) forgot to translate — in every script — plus the naive text-splitting that breaks non-space languages like Thai and CJK.

GitHub ↗ npx github:Otto-OttoSpace/lahja
01 What it does

AST-accurate

Real parsing, not regex — no false positives on code, no missed literals.

Every script

Catches single-token CJK / Thai / Arabic UI strings a Latin-only linter drops.

Segmentation smell

Flags naive space-splitting on no-space scripts and recommends Intl.Segmenter.

Baseline mode

Adopt on an existing repo: accept today's debt, fail only on new strings.
