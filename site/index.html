lahja · لهجة

AI baked English into your UI. Find every string it forgot to translate.

AI codegen hardcodes text into JSX, formats dates and currency with no locale, and skips <html lang>. It looks done — until you ship in a second language. lahja reports every user-facing string that isn't translated yet — AST-verified, so it never mistakes your live code for UI text.

$ npx lahja .

What it catches

  • Hardcoded JSX / markup text — <h1>Your cart</h1> → wrap in t()
  • Hardcoded string literals — const label = 'Add to cart', alert('Saved'), toast(`…`)
  • User-facing attributes — placeholder, title, alt, aria-label, label
  • Un-localized formatting — a bare toLocaleDateString() with no locale
  • Hardcoded currency — $99.00 → Intl.NumberFormat
  • Missing <html lang>

Zero mistakes, by design

Detection is AST-verified (Babel). A TS generic like Array<string> never welds across lines into "text"; <html> inside a string is never a missing-lang; a Vue :placeholder="msg" binding is never flagged; keys, ids, classNames and imports are left alone. Every one of those is a permanent test in node --test.

Adopting on a legacy repo? npx lahja . --baseline accepts today's debt and fails only on new strings. --suggest proposes a t()-wrap — and writes nothing.
